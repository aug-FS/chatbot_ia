# Entrelinhas — frontend

Interface React + Vite para o chatbot literário.

## Executar

```bash
cp .env.example .env
npm install
npm run dev
```

O backend deve estar disponível em `http://localhost:8000`. Para usar outro endereço,
altere `VITE_API_URL` no arquivo `.env`.

## Build de produção

```bash
npm run build
```
